# Offline Tailwind CSS Batch - Learning Resources

A course workspace for learning CSS and Tailwind CSS through small examples, reusable UI sections, and practice projects.

## Repository Areas

- `01-installation/` - Tailwind setup examples
- `02-Code/` - lesson code and practice files
- `04-Notes/` - reference notes
- `TOC/` - topic or course navigation
- Project folders such as `navbar/`, `profile-card/`, `responsive-footer/`, `responsive-hero-section/`, and `shopping-card/`

The repository may include additional lessons and project experiments over time.

## Run the Examples

```bash
git clone https://github.com/Coderudit05/offline-tailwind-css-3rd-Nov-22-Nov-.git
cd offline-tailwind-css-3rd-Nov-22-Nov-
```

Open standalone HTML files directly in a browser or use VS Code Live Server. Some subfolders demonstrate different Tailwind installation approaches, so check the specific folder before running commands.

## Suggested Learning Path

1. Understand the available Tailwind installation methods.
2. Practice spacing, typography, color, and layout utilities.
3. Build responsive components such as cards, navbars, and footers.
4. Inspect responsive behavior at different viewport widths.
5. Combine the components into a larger page.

## Note

This is a teaching workspace with multiple independent examples, not a single production application. Use the instructions for the specific lesson or project you want to run.
